1.	El sistema debe responder a consultas de inventario bajo 3 segundos.

2.	El sistema debe cargar el panel de equipos asignados bajo 2 segundos.

3.	El sistema debe generar reportes de 500 registros bajo 8 segundos.

4.	El sistema debe procesar 50 solicitudes simultáneas bajo 5 segundos de tiempo promedio.

5.	El sistema debe registrar todas las acciones de usuarios con fecha, hora y usuario responsable.

6.	El sistema debe restringir el acceso a funciones según el rol del usuario.

7.	El sistema debe proteger los datos de los activos y asignaciones mediante encriptación.

8.	El sistema debe requerir autenticación de dos factores para cambios en el inventario.
9.	El sistema debe permitir a un usuario sin experiencia realizar una solicitud de equipo en menos de 60 segundos.

10.	El sistema debe mostrar los estados de los equipos mediante colores e iconos reconocibles.

11.	El sistema debe tener una interfaz compatible con computadoras y dispositivos móviles con sistemas operativos por encima del 2017.

12.	El sistema debe permitir navegar entre las pantallas principales en máximo 3 clics.

13.	El sistema debe estar disponible mínimo el 99% del tiempo durante horas laborales.

14.	El sistema debe tener un tiempo de recuperación después de fallos menor a 15 minutos.

15.	El sistema debe realizar copias de seguridad automáticas cada 24 horas.

16.	El sistema debe soportar hasta 300 usuarios activos de forma simultánea.

17.	El sistema debe permitir agregar nuevos tipos de activos sin modificar la estructura principal.

18.	El sistema debe manejar hasta 10.000 activos registrados sin pérdida de rendimiento.

19.	El sistema debe permitir aumentar la cantidad de usuarios sin requerir cambios mayores en la arquitectura.

20.	El sistema debe permitir agregar nuevos reportes sin necesidad de reprogramar el núcleo.

21.	El sistema debe tener código fuente documentado y modular.

22.	El sistema debe permitir realizar actualizaciones sin detener el servicio más de 30 minutos.

23.	El sistema debe registrar errores de forma clara para facilitar su diagnóstico.
