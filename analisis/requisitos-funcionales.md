1.	El sistema debe permitir buscar y consultar la información detallada e histórica de cualquier activo registrado, incluyendo asignaciones, devoluciones, reparaciones y cambios de responsable, de acuerdo con los permisos del rol de responsable de Activos. (HU-21)

2.	El sistema debe registrar todos los activos de la empresa (laptops, celulares, herramientas) con código único, tipo, marca, modelo, ubicación y estado actual. (HU-01)

3.	El sistema debe mostrar el responsable actual de cada activo (nombre completo y fecha de asignación). (HU-02)

4.	El sistema debe actualizar automáticamente el responsable cuando un equipo cambia de persona. (HU-09)

5.	El sistema debe generar automáticamente un acta digital de entrega al asignar un equipo. (HU-03)

6.	El sistema debe incluir en el acta los datos del equipo, datos del empleado y fecha de entrega. (HU-11)

7.	El sistema debe enviar notificaciones al responsable de Activos cuando un equipo se acerque a su fecha de devolución. (HU-04)

8.	El sistema debe enviar notificaciones al responsable de Activos cuando un equipo haya superado su fecha de devolución. (HU-04)

9.	El sistema debe generar reportes de equipos asignados, disponibles y pendientes por devolver. (HU-05)

10.	El sistema debe permitir filtrar los reportes por estado del equipo y por responsable. (HU-17)

11.	El sistema debe permitir a los empleados registrar una nueva solicitud de equipo indicando el tipo de activo y el motivo. (HU-06)

12.	El sistema debe asignar un número de seguimiento único a cada solicitud registrada. (HU-06)

13.	El sistema debe mostrar al empleado la lista de todos los equipos que tiene asignados actualmente. (HU-07)

14.	El sistema debe mostrar la fecha de entrega y el estado actual de cada equipo asignado al empleado. (HU-07)

15.	El sistema debe permitir al empleado registrar la devolución de un equipo. (HU-08)

16.	El sistema debe actualizar automáticamente el estado del equipo a “Disponible” al registrar la devolución. (HU-09)

17.	El sistema debe permitir al empleado firmar digitalmente el acta de entrega al recibir un equipo. (HU-08)

18.	El sistema debe registrar la validación del estado y actualizar la responsabilidad en el sistema (HU-09).


19.	El sistema debe enviar una notificación por correo al empleado cuando el equipo solicitado cambia al estado “Listo para recoger”, incluyendo la ubicación del equipo y la ubicación de entrega. (HU-13)

20.	El sistema debe registrar la fecha, descripción del problema y evidencia adjunta en cada reporte de daño. (HU-10)

21.	El sistema debe permitir al empleado firmar digitalmente el documento de entrega al momento de recibir un equipo, registrando la firma junto con la fecha y hora, para confirmar la recepción y el buen estado del equipo. (HU-11)

22.	El sistema debe incluir en la notificación la información del equipo y la ubicación de entrega. (HU-13)

23.	El sistema debe permitir a los empleados reportar un equipo dañado o que necesita revisión. (HU-12)

24.	El sistema debe permitir al Aprobador aprobar o rechazar cada solicitud individualmente. (HU-14)

25.	El sistema debe incluir en la notificación los datos del equipo y la descripción del problema reportado. (HU-10)

26.	El sistema debe registrar el historial de reparaciones y mantenimientos de cada equipo. (HU-16)

27.	El sistema debe mostrar el historial completo de reparaciones al consultar un equipo. (HU-16)

28.	El sistema debe generar reportes consolidados de equipos asignados en formato PDF sobre los activos disponibles y dañados. (HU-05)

29.	El sistema debe registrar todas las acciones realizadas sobre los activos (asignaciones, devoluciones, cambios de responsable y bajas). (HU-18)

30.	El sistema debe guardar en cada registro la fecha, hora y el usuario que realizó la acción. (HU-18)

31.	El sistema debe permitir al usuario iniciar sesión mediante credenciales (usuario y contraseña) y asignar automáticamente el acceso solo a las funciones correspondientes a su rol (responsable de Activos, Empleado, Aprobador, Técnico de Soporte o Gerente). (HU-19)

32.	El sistema debe permitir al responsable de Activos registrar la baja de un equipo, indicando el motivo (pérdida, daño irreparable o fin de vida útil), y actualizar automáticamente el estado del equipo a “Baja” en el inventario. (HU-20) 

33.	El sistema debe permitir al responsable de Activos consultar el historial completo de cada equipo, incluyendo todas las asignaciones previas, devoluciones, reparaciones y cambios de responsable. (HU-21)

34.	El sistema debe enviar notificaciones al Técnico de Soporte cuando se reporte un equipo dañado o que necesita revisión. (HU-15)
