# Matriz de Trazabilidad: Objetivos ↔ Objetivo General ↔ Fases

| **Objetivo Específico**                                        | **Relación con el Objetivo General**                                                  | **Fase de la Ruta** |
| :------------------------------------------------------------- | :------------------------------------------------------------------------------------ | :-----------------: |
| **Objetivo Específico 1:** Analizar los procesos actuales      | Permite identificar y documentar los problemas reales en la gestión de activos fijos. |     **Análisis**    |
| **Objetivo Específico 2:** Diseñar el modelo y la arquitectura | Define la solución técnica que responde a los problemas identificados.                |      **Diseño**     |
| **Objetivo Específico 3:** Construir el sistema                | Implementa la solución que materializa el modelo y cubre las necesidades detectadas.  |   **Construcción**  |
| **Objetivo Específico 4:** Validar el sistema                  | Garantiza que el sistema cumple los requisitos y resuelve los problemas documentados. |    **Validación**   |
